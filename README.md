# UAS Program Management System

## Project Overview

I am building a Microsoft 365-based Unmanned Aircraft System (UAS) Program Management System to organize and manage the information associated with operating a UAS program.

A UAS program involves more than tracking aircraft. It includes aircraft and equipment, batteries, pilot qualifications and training, flight activity, aircraft checkouts, maintenance, support equipment, vendors, and other records needed to manage the program.

I began developing the UAS Program Management System (UAS PMS) to bring this information into a more structured and connected environment. My goals are to reduce repetitive data entry, improve data consistency, simplify access to information, and make reporting more efficient.

The project uses Microsoft Lists as the core data structure, Microsoft Forms for controlled data entry, and Microsoft Excel and Power Query for reporting and analysis. Power Automate workflows and legacy-data migration are still being developed.

This repository documents the project architecture, major milestones, design decisions, testing, problems encountered, solutions implemented, lessons learned, and future improvements.

## Project Status

The core data structure is under active development. Multiple Microsoft Lists and their associated fields and relationships have been designed and built. Portions of the Forms, Lists, and Excel workflow have also been implemented and validated.

Current development work includes completing the remaining data structures, expanding reporting capabilities, developing additional workflow automation, and preparing for controlled migration of legacy data into the new system.

## Project Goals

The goals of this project are to:

- Organize UAS program information into a structured system.
- Reduce repetitive and inconsistent data entry.
- Create relationships between related operational records.
- Improve the ability to retrieve and analyze information.
- Develop more efficient reporting processes.
- Reduce manual administrative work where practical.
- Create a system that can be maintained and expanded over time.
